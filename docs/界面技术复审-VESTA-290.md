### 已逐类核对的告警

- **low-contrast**：确认标签、SKU、分类、导航分组、图例、页脚等。检测器还发现搜索placeholder #7a8494/白底约3.8:1，补入A01。商品SKU像素检查约2.4–2.8:1，与人工计算一致。
- **undersized-ui-text / tiny-text / wide-tracking**：真实8–10px信息文字纳入A06。品牌字标、纯装饰序号不独立计数；11px文字不一律定为违反WCAG，需按内容用途评估。
- **overused-font**：源码style.css:2有Inter，但六个渲染状态的computed font-family都是Segoe UI / PingFang SC / Microsoft YaHei / sans-serif，来自refinement.css覆盖。不判为实际使用Inter；该静态提示不能推翻运行证据。
- **repeating-stripes-gradient**：refinement.css:359是趋势图水平网格，有读图用途，不是装饰条纹，不要求移除。
- **月份文字的gradient低对比度**：检测器取网格浅灰色得到约4.4:1；标签实际背景位置与网格线需要更细像素定位，暂不把这6条作为已确认新增缺陷。其他不依赖此判断的对比度失败已充分确认。
- **skipped-heading**：总览h1后接h3属实（workspace.tsx:711等）。可在后续语义整理时改用h2，但跳级本身不足以单独判定本项目WCAG失败，不增加高优先级条目。
- **hero-eyebrow-chip / kicker-above-heading / nested-cards / unbalanced-heading**：形状检测属实；登录辅助标题、门户公司摘要卡及手机标题换行未证明导致操作或理解失败。这些是视觉启发式建议，不自动算业务应用技术缺陷，也不授权重设计。
- **表单扫描中的背景内容**：部分命中在遮罩底层页面；作为对应页面的既有问题去重，不再新增“弹窗缺陷”。

## 按优先级排列的发现

### A01 · P1 · 普通文字对比度不足

- **类别/位置**：可访问性；web/style.css:816（label）、:695–724（SKU）；web/refinement.css:69、:75、:167、:382、:590、:642、:710，以及placeholder规则。
- **证据/复现**：客户与跟进→新增客户，11px标签3.90:1；导航分组3.78:1；图例4.28:1；分类4.23:1；SKU2.44–2.85:1；页脚3.59:1。门户搜索placeholder约3.8:1。官方检测与本轮DOM复查交叉确认。
- **影响**：字段用途、商品编号与重要提示难以辨认，低视力和窄屏阅读受影响。
- **标准/建议**：普通文字按WCAG1.4.3检查4.5:1；统一语义文字颜色并按实际背景复核。建议 `$impeccable harden`。标准链接沿用[W3C对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

### A02 · P1 · 关闭与附件选择控件无可访问名称

- **类别/位置**：可访问性；web/main.tsx:3406共享表单X按钮、:3832合同file input。
- **证据/复现**：本轮35状态脚本再次命中新增客户无名按钮及合同档案无label/aria-label的文件输入；此类问题不是检测器静态零告警就能排除。
- **影响/标准**：辅助技术无法可靠识别用途，涉及WCAG4.1.2及标签关联。
- **建议**：关闭按钮提供双语名称，文件输入增加关联的可见标签；保留现有焦点循环与返回。建议 `$impeccable harden`。参见[W3C名称、角色、值](https://w3c.github.io/wcag/understanding/name-role-value.html)。

### A03 · P1 · 英文页面仍声明中文

- **类别/位置**：可访问性/本地化；index.html:1，web/main.tsx:182与:1248。
- **证据/复现**：EN切换后Overview/Products为英文，但本轮DOM及CDP元数据均为lang=zh-CN。
- **影响/标准**：辅助技术的朗读语言选择错误，涉及WCAG3.1.1。
- **建议**：语言状态驱动html lang，并处理退出登录后中文界面及局部混合语段。建议 `$impeccable harden`。参见[WCAG页面语言](https://www.w3.org/TR/wcag/#language-of-page)。

### A04 · P2 · 英文目录分类漏译

- **类别/位置**：实现一致性；web/main.tsx:1624已有筛选映射，:1651商品卡直接显示p.category。
- **证据/影响**：英文筛选为Everyday gifts等，卡片仍为“日用礼品/商务出行/办公文具/包装配套”；同一类别不一致，英文客户难以对应。
- **建议**：筛选和卡片共用分类显示函数，保留未知值回退，不改业务主数据。建议 `$impeccable clarify`；无独立WCAG违规判断。

### A05 · P2 · 主题变量与旧色覆盖混用

- **类别/位置**：主题/实现一致性；web/main.tsx:34–37四份CSS；refinement.css:5–6的--green/--teal实际为钴蓝；style.css的标签和SKU仍继承旧色。
- **证据/影响**：新版背景配旧文字色造成A01的一部分问题；主题变更容易遗漏，变量名误导维护。四份CSS本身不是错误，问题是实际覆盖残留。
- **建议**：记录实际生效的accent/text/surface/status语义变量与screen/print边界，再有限归一。建议 `$impeccable document` 后 `$impeccable polish`。不要求新增暗色模式。

### A06 · P2 · SKU及说明文字字号过小（本轮新增独立项）

- **类别/位置**：可访问性/响应式；web/style.css:704的SKU为9px，:911页脚8px；:246等本机提示为9px；refinement.css:70导航分组10px。
- **证据**：官方undersized-ui-text与实际截图一致，手机门户仍保持这些尺寸。此前已有字号观测，本轮将其作为独立可读性改进项，不称新回归。
- **影响**：即使修正颜色，用户仍需放大才能清楚阅读型号和运行说明；阅读负担不能仅通过对比度修复解决。
- **标准/建议**：这是产品可读性标准，WCAG没有通用“至少11px”硬性门槛，不冒充AA违规。建议 `$impeccable typeset` 调整信息文本字号和行高，并验证320px目录、页脚与表格。品牌字标不与业务信息一起机械放大。
